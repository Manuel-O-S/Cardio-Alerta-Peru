# docs

Documentación del proyecto.

- `Arquitectura_Cardio_Alerta_Peru.docx` — cómo está armado el sistema de punta a
  punta (tarea B01). Léelo antes de tocar cualquier otra carpeta.
- `Tamizaje_Numerico.md` — el módulo de tamizaje por oximetría: decisiones
  clínicas, bandas de altitud y qué falta antes de usarlo con pacientes reales.
  **El documento de arquitectura es anterior a este módulo**, así que donde los dos
  hablen del núcleo del producto, manda este.
- `Contrato_API.md` — qué manda y qué recibe cada endpoint.
- `Propuesta_Proyecto.md` — **la premisa vigente del proyecto.** Qué problema
  resuelve, para quién, y las decisiones de diseño que lo sostienen. Base del
  Anexo 1.
- `Datasets_Fase_Imagen.md` — evaluación de datasets de imagen médica y sustento
  de por qué el análisis de imagen quedó fuera del alcance.
- `Anexo2_Uso_IA_Generativa.md` — declaración de uso de IA generativa exigida por
  las bases. **Borrador: cada integrante debe completar su sección.**
- `anexo1_entrega_final.docx` — formato de entrega final exigido por las bases
  (Said, tarea W08). Se agrega más adelante.
- `anexo2_declaracion_ia.docx` — declaración de uso de IA generativa (Said,
  tarea W11). Se agrega más adelante, con el registro de usos que se va llevando
  desde ahora.
